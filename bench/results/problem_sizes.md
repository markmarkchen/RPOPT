# Benchmark problem sizes

Generated by `cargo run --profile gate --example problem_sizes` (`examples/problem_sizes.rs`); nothing is solved or timed.

- **theta**: parameters. **x**: variables (the same before and after preprocessing).
- **constraints**: rows of `A x <= b + F theta` (equalities included). `a → b` means the JSON file has `a` rows and the solvers see `b`: loading a problem merges duplicate rows and drops redundant ones. The result files of `ppopt_bench` (`<name>/info`) record the processed count.
- **theta rows**: rows of the parameter-space constraints `A_t theta <= b_t`, same notation.
- **regions**: critical regions of the archived solution of the solver in the last column, from `solution_archive_manifest_1feb98b3ced6.csv`. For the degenerate mpLPs the partition is not unique, so another valid solver can report a different count.
